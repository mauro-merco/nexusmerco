### Known Issues
- `--` summary rows now filtered from campaign data via `name.trim().startsWith('--')`
- Admin check on user creation API now uses `jose.jwtVerify` instead of `supabase.auth.getUser` (fixes "Solo admins" error)
- `/api/ai/chat` needs `opencode serve` running (port 4096). If not running, endpoint returns 503 with "Ejecuta `npm run ai`". The serve process must be restarted after a reboot.
- **Free Zen tier of OpenCode (Console provider) does NOT work from `opencode serve`**: it returns "Error from provider (Console): OpenCode's free tier can only be used from within OpenCode". That's a platform restriction (free tier is TUI-only). The dashboard AI now uses the **Anthropic provider**: `opencode.json` (project root) declares `provider.anthropic.apiKey = {env:ANTHROPIC_API_KEY}` and default model `anthropic/claude-sonnet-4-5`; the `dashboard`/`writer` agents declare the same `model:` in their frontmatter, and both `/api/ai/chat` and `/api/ai/document` force `model: { providerID, modelID }` per prompt. Set `ANTHROPIC_API_KEY` in the env that runs `npm run ai` (and optionally `OPENCODE_MODEL=provider/model` to change model), then restart the serve process.
